# Valet PWA (preview)
Run: `python3 valet/server.py` (port 8792), open on phone, Add to Home Screen. Works without the server too (in-browser mock).

Features: bottom tab bar (Talk, Agents, Meetings, Tasks); text chat; hold-to-record voice notes (MediaRecorder, playable bubble, Web Speech transcript where supported, fallback if mic denied); hands-free conversation (Web Speech API); CEO/project meetings; task tray.
Mocked: Bags replies (rule-based), delegation, specialists/CEOs (disconnected), status task. No paid providers, no secrets.
Fonts: Rajdhani, Manrope (SIL OFL), self-hosted. Icons: Tabler Icons (MIT).
